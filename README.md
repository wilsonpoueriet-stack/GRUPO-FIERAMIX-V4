# GRUPO FIERAMIX.COM Enterprise 2026 — Primer Entregable

Incluye:
- Header premium y navegación responsive.
- Hero principal inspirado en la plantilla aprobada.
- Reproductor global en vivo.
- Metadatos RadioBOSS para las 9 emisoras.
- Canción, artista y oyentes en cada tarjeta.
- Historial visual, Top 10, noticias y club de oyentes.
- Barra inferior persistente.

## Instalación

```bash
npm install
npm run dev
```

## Variables de Netlify
Use las variables ya configuradas en el proyecto. Consulte `.env.example`.

## Publicación

```bash
npm run build
git add .
git commit -m "Enterprise 2026 - primer entregable Home"
git push origin main
```
