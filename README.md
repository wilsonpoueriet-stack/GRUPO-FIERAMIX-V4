# GRUPO FIERAMIX V4

Portal oficial de **GRUPO FIERAMIX.COM — La red latina que mueve el mundo**.

## Requisitos

- Node.js 20 o superior
- npm 10 o superior

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Verificación de producción

```bash
npm run build
npm start
```

## Despliegue en Netlify

1. Importa el repositorio desde GitHub.
2. Comando de compilación: `npm run build`.
3. Directorio de publicación: `.next`.
4. Netlify detectará Next.js automáticamente.

## Emisoras

Las emisoras, logos, eslóganes y URLs se administran en `data/stations.ts`.
